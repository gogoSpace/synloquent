# Supported versions and dependencies

Date: 2026-10-07. Status: 0.1.0 beta.

Server archive consumers are tested on Laravel 12.55.1 and 13.34.0 with PHP 8.4.7, PostgreSQL 18.3 and MariaDB 11.7.2. The package permits PHP ^8.3 and Illuminate ^12.55 or ^13.34. The tested versions are narrower than those dependency ranges. Oracle MySQL is not qualified.

The native example pins React Native 0.87.1, React 19.2.8, OP-SQLite 18.2.5 and scheduler 0.27.0. It uses Hermes, asynchronous SQLite and the packaged native SHA256 implementation. Node 22.21.1 and TypeScript 5.9.3 are the verified development versions. Native functional coverage uses an Android emulator and an iOS simulator. Physical-device performance qualification is future work.

Core client runtime dependencies are empty. React, native SQLite and native SHA256 imports are isolated behind optional exports. The optional crypto provider uses the platform CommonCrypto and java.security.MessageDigest APIs with no additional cryptography dependency. The previous @noble/hashes test-consumer dependency was removed after the public system provider replaced it. Node's SQLite module is used only by test adapters. Drizzle is omitted because a second query abstraction would add contract work without reducing the required compiler parity tests.
